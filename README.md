# lpy-autocomplete (Deprecated)

> **This package is deprecated.** Completion, documentation, and introspection are now provided by the nREPL server built into [lispython](https://github.com/jetack/lispython) (v0.4.5+). Use `lpy --nrepl` instead.
>
> Editor integration:
> - **Emacs**: [lpy-mode](https://github.com/jetack/lpy-mode) connects to nREPL automatically
> - **VS Code**: [vscode-lispython](https://marketplace.visualstudio.com/items?itemName=jetack.vscode-lispython) connects to nREPL automatically

Autocompletion and introspection tools for [lispython](https://github.com/jetack/lispython).
